# Requirements delta — 040-publication-image

## NEW

- **R-PUB-1** The Publication card on `/story` must render a photo alongside its text: recovered
  from git history into the `project_images/` drop-zone, published through the existing
  `scripts/build-images.mjs` pipeline (never hand-copied into `public/`), and exposed through the
  `images.projects` manifest like every other project image.
- **R-PUB-2** `publication` in `src/content/site.ts` gains `image` (a key into `images.projects`)
  and `imageAlt` (a literal description of what the photo actually shows, not a generic caption).
- **R-PUB-3** The image renders small and to the right of the text on desktop
  (`md:grid-cols-[1fr_200px]`) and above the text on mobile, framed with `rounded-2xl border
  border-white/10` to match the existing project-card frame, inside the same `<Reveal>` idiom as
  neighbouring `/story` sections.

## CHANGED

- None. This is additive only — no existing requirement's behaviour changes. The Publication
  section's text content, links, and copy are untouched.

## UNCHANGED / constraints honoured

- **Images are built, never hand-copied** (`AGENTS.md`): the recovered JPEG goes through
  `PROJECT_MAP` → `build-images.mjs` → WebP, exactly like every other `project_images/` entry.
  `src/data/images.json` stays a generated manifest, regenerated by `predev`/`prebuild`, not
  hand-edited.
- **Content is code**: the new `image`/`imageAlt` fields live in `src/content/site.ts`, not
  hardcoded in `src/app/story/page.tsx`.
- **No gallery duplication**: verified the recovered photo (SHA-256
  `3ab21306594bd883a6318fbecbf4d607cb7c0e7172a1885ccaa7b7fea10038ae`) has no match, exact or visual,
  among the 15 `gallery/*.jpeg` files — including the four that happen to share its 1200×1600
  dimensions (all four are other shots from the same Korea trip, none is the photo-wall image).
- **No architectural change**: static export (`output: "export"`), `images.unoptimized: true`, and
  the existing drop-zone → manifest → component data flow are all unchanged. No new dependency.
