## Intent

Owner supplied a newer résumé (`H:\mywebsite\nlp resume.pdf`, 151821 bytes, replacing the committed
141496-byte copy) and seven new JPEGs from a hike/city outing (`H:\mywebsite\new pics\`) to add to the
gallery. `person.resume` in `src/content/site.ts` already points at `/resume.pdf`; no route or content
key change was needed, only the underlying file bytes and one more drop-zone batch.

## Sources

- Résumé: `H:\mywebsite\nlp resume.pdf` → both committed copies (`resume.pdf` at the repo root,
  `public/resume.pdf`), per AGENTS.md — the root file is copied to `public/` and committed directly,
  not generated by a script.
- Gallery: seven JPEGs from `H:\mywebsite\new pics\`, named `WhatsApp Image 2026-08-27 at ....jpeg`.
  Copied as-is into the `gallery/` drop-zone. Filename sort (`scripts/build-images.mjs` sorts
  `gallery/*` before numbering) puts them after the existing eight `2026-01-27`-dated files, so
  gallery indexes 1–8 (`01.webp`–`08.webp`) are unchanged and the new files become `09.webp`–`15.webp`.
