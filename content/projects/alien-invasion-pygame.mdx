## Overview

A Space-Invaders-style shooter — my first program with Pygame, written while learning the library — plus a handful of smaller pygame experiments kept in the same repository.

## What it does

- `alien_invasion.py` — the main game: a ship at the bottom of a 1200x800 window moves left and right with the arrow keys, fires up to 3 bullets at once with space, and a fleet of aliens marches across the screen and drops down when it hits an edge. The player starts with 3 lives, tracked in `Gamestats`.
- `settings.py` — screen size, ship and bullet speed, bullet size and colour, and how many bullets can be on screen at once.
- `game_functions.py` — event handling, fleet creation, bullet and alien updates, and collision detection.
- Side experiments in the same folder: a second shooter variant (`side_shooter.py`), a game where you catch falling balls (`catch_ball.py`), and a sprite-drawing script (`naruto.py`).

## Status and limitations

A learning project, per the README: no tests, no requirements file, and no scoring or levels. The sprite image paths referenced in the scripts do not match where the `.bmp` files actually sit in the repository, so running it needs either creating the expected folders or editing the paths.
