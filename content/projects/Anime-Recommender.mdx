## Overview

An anime recommendation system built on **collaborative filtering** — it recommends titles to a user based on the preferences of other users with similar taste.

## Using it

- Type the anime's original English title exactly as released (matching spacing and case, as listed on sites such as hianime.to).
- The trained models are too large for the repository and are hosted in a [Google Drive folder](https://drive.google.com/drive/folders/1D6PQBEFtlem0NQEFVDqN8c1R0jcUxMoj?usp=drive_link).
