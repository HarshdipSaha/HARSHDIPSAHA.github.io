# Reference: content schema

Two sources of copy, one generated manifest:

- **`src/content/site.ts`** — every word that is not a project case study. Plain TypeScript object literals, one `export const` per section. There is no separate types file; shapes are inferred from the literals and the components that destructure them are the contract. Where this page and that file disagree, the file wins.
- **`content/projects/*.mdx`** — one case study per file, parsed by `gray-matter` in `src/lib/projects.ts`.
- **`src/data/images.json`** — generated by `scripts/build-images.mjs`; read through `src/lib/projects.ts`.

All fields are plain `string` unless stated. No JSX in content.

## Project MDX frontmatter

One file per project in `content/projects/*.mdx`. Parsed by `gray-matter` in `src/lib/projects.ts` (`getProjects`). **Slug = filename minus `.mdx`, lowercased.** Body is rendered by `next-mdx-remote/rsc` with `remark-gfm` inside `.prose`.

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes | Card title and page h1 |
| `publishedAt` | `string` | effectively | `YYYY-MM-DD`. Sorts `/projects` newest first; `year` on the card; long date on the page. Missing → `2024-01-01` |
| `summary` | `string` | yes | Card copy (2-line clamp) and page lede. Missing → `""` |
| `images` | `string[]` | no | Only `images[0]` is used. Must be `/img/projects/<slug>.webp`; the basename is the key into `images.projects`. Unknown key → no image, no error |
| `link` | `string` | no | Renders the tangerine "Repository" pill |

Anything else in the frontmatter is ignored. The resulting `Project` type is `{ slug, title, date, year, summary, link?, image?: { src, w, h }, body }`.

`content/writing/*.mdx` (three blog posts, frontmatter `title, publishedAt, summary, image, tag`) is **not read by any code**.

## Image manifest — `src/data/images.json`

Generated. Shape:

```json
{
  "gallery": [{ "src": "/img/gallery/01.webp", "thumb": "/img/gallery/01-s.webp", "w": 1200, "h": 1600 }],
  "projects": { "atomnet": { "src": "/img/projects/atomnet.webp", "w": 762, "h": 402 } },
  "me": { "src": "/img/me.webp", "w": 960, "h": 960 }
}
```

Exposed by `src/lib/projects.ts` as `gallery` (`(ImageMeta & { thumb })[]`), `projectImages` (`Record<string, ImageMeta>`), `portrait` (`ImageMeta`), where `ImageMeta = { src, w, h }`. See [build-scripts.md](build-scripts.md).
