## Guidelines

- A contribution counts only once its PR is **merged into `main`**. An open or closed-but-unmerged
  PR does not count (example: Gemini Antigravity raised a PR that was never merged, so it is not
  listed as a contributor).
- **Self-registration rule:** whenever an LLM/AI agent does work that gets merged into `main`, that
  model adds its own name to the list above — in the same PR, if it's able to edit files — or the
  owner (Harshdip Saha) adds it on the model's behalf if it can't.
- List models by name (e.g. "Claude Sonnet 5"), not by the tool that ran them (e.g. not "Claude
  Code", which is a CLI, not a model). If a model is already listed, don't add a duplicate entry.
